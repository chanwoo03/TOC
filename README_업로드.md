# TOC 사이트용 이번 주 자료

이 폴더의 **내용물**을 `C:\Study\inhatc_c\TOC`에 복사합니다. `docs` 폴더는 기존 `docs`와 병합하고, 같은 이름의 `docs` 파일은 교체합니다.

- `docs/index.html`, `docs/app.js`: 발표 페이지의 제목과 10장 목록
- `docs/slides/slide-01.png` ~ `slide-10.png`: 이번 주 발표 슬라이드 이미지
- `docs/downloads/MediSync-AI.pptx`: 이번 주 PPT 다운로드 원본
- `구현_소스/`, `의약품_데이터/`: 저장소에 함께 둘 개발 자료. GitHub Pages 웹 화면에서는 직접 표시되지 않음

복사한 뒤 VS Code에서 `C:\Study\inhatc_c\TOC`를 열고, 소스 제어에서 변경 파일을 확인하여 **커밋 → 푸시(또는 변경 사항 동기화)** 해야 GitHub Pages 사이트가 갱신됩니다. 로컬 폴더에 복사만 해서는 사이트가 바뀌지 않습니다.

GitHub Pages 설정이 `main` 브랜치의 `/docs`를 사용한다면 배포 후 `https://chanwoo03.github.io/TOC/`에서 확인할 수 있습니다.
