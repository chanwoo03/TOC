# MediSync AI / TOC

이 저장소의 **최상위 폴더**가 React 데모의 작업 폴더입니다. VS Code에서 `C:\Study\inhatc_c\TOC`를 열고 `src`를 수정합니다.

## 폴더

- `src/`, `index.html`, `package.json`: React 웹 데모 소스
- `docs/`: GitHub Pages 발표 페이지와 PPT 다운로드 파일
- `public/presentation/`: Cafe24 데모 안에서 열리는 11월 11일 발표 페이지
- `의약품_데이터/`: 일반의약품 100개 데이터 설계와 ERD 설명
- 프로젝트 제안서·소프트웨어 설계서 `.docx`: 기획 문서
- `.vscode/sftp.json`: Cafe24 데모 업로드 설정. Git에는 올리지 않음

원본 e약은요 CSV와 이전 버전·중복 파일은 저장소 밖 `C:\Study\inhatc_c\TOC_보관_20261104`에 보관합니다.

## 실행

```powershell
cd C:\Study\inhatc_c\TOC
npm install
npm run dev
```

웹 배포용 파일을 다시 만들 때는 `npm run build`를 실행합니다. 결과는 `dist/`에 생성되며 GitHub에는 올리지 않습니다. GitHub Pages 발표 사이트는 별개로 `docs/`에 있습니다.

11월 11일 버전은 `http://chanwlab.com/medisync-demo/`에 올렸습니다. 앱 상단의 **발표자료 보기**를 누르면 Cafe24의 발표 페이지가 열리고, 그 페이지에서 PPT를 내려받을 수 있습니다. `docs/`의 같은 발표자료는 GitHub에 푸시하면 기존 GitHub Pages 발표 주소에도 반영됩니다.

현재 웹 데모의 OCR과 주의정보는 시범 기능입니다. 일반약 100개는 제품·성분·제품별 e약은요 원문이 연결돼 있습니다.

## 함께 먹기 화면

두 항목을 선택하면 (1) 정확한 품목번호가 있는 일반약끼리의 공통 성분,
(2) 출처를 확인하고 적용 대상을 지정한 주의 규칙,
(3) 각 제품의 이상반응 원문을 별도로 표시합니다.
현재 주의 규칙은 예시 약·영양제 5건과 일반약 제품 조합 1건입니다.
`의약품_데이터`의 문자열 매칭 후보 30건은 검토 자료이며 앱 경고에 쓰지 않습니다.
규칙이 보이지 않아도 안전하다는 뜻은 아닙니다. 직접 입력 제품은 자동 판정하지 않습니다.

## 2주차까지 구현한 내용

- 일반약 100개, 성분 142개, 제품·성분 연결 341건과 제품별 원문 100건을 연결했습니다.
- 약을 등록하고 복용 시간을 정하거나 나중에 `내 약`에서 수정할 수 있습니다.
- 예정 시간이 지나면 페이지 안에 약별 3줄 안내가 표시됩니다. `먹었어요`, `10분 뒤 다시 알림`, `복용하지 않음`을 직접 선택해야 기록이 바뀝니다. 10분 재알림은 새로고침 후에도 유지됩니다.
- 복용 완료·미복용 이력을 날짜별로 확인하고 수정할 수 있습니다.
- 출처와 적용 대상을 확인한 주의 규칙 6건만 화면에 표시합니다.

알림은 페이지를 열어 둔 동안 동작합니다. 현재 Cafe24 주소는 HTTP이므로 브라우저 밖의 시스템 알림은 사용할 수 없고, 화면 안 알림을 사용합니다. OCR 정확도 개선과 화면 전체 검증은 이후 주차 작업입니다.

확인 명령: `npm test`, `npm run build`
