# MediSync AI 데모 — 처음 시작하기

이 프로젝트는 **React로 만든 웹 데모**입니다. VS Code에서 수정할 것은 `src` 폴더의 파일입니다. `dist/assets/index-...js`처럼 이름이 긴 파일은 배포용으로 자동 압축된 결과라 읽거나 직접 수정하지 않아도 됩니다.

## 1. 어떤 ZIP을 열어야 하나요?

| 파일 | 용도 |
|---|---|
| `MediSync_AI_React_소스.zip` | VS Code에서 코드를 읽고 수정할 때 |
| `MediSync_AI_웹업로드용.zip` | 완성된 웹 파일을 호스팅에 올릴 때 |

**개발을 시작할 때는 React 소스 ZIP을 압축 해제하세요.**

## 2. VS Code에서 실행하기

1. PC에 **Node.js LTS**를 설치합니다. 이미 설치했다면 건너뛰세요.
2. VS Code를 열고 **파일 → 폴더 열기**에서 압축을 푼 `MediSync_AI_React_소스` 폴더를 선택합니다. `package.json`이 보이면 맞는 폴더입니다.
3. 상단 메뉴 **터미널 → 새 터미널**을 엽니다.
4. 아래 명령을 한 줄씩 입력합니다.

```bash
npm install
npm run dev
```

5. 터미널에 표시되는 `http://localhost:5173/` 주소를 브라우저에서 엽니다. 실제 포트 번호가 다르면 **터미널에 나온 주소**를 사용하세요.
6. 코드를 고치고 `Ctrl + S`로 저장하면 브라우저 화면이 자동으로 바뀝니다.

Windows PowerShell에서 `npm` 실행이 막히면 `npm.cmd install`, `npm.cmd run dev`를 입력하세요. 서버를 종료할 때는 터미널에서 `Ctrl + C`를 누릅니다.

## 3. 어디를 수정하면 되나요?

| 하고 싶은 일 | 열 파일 |
|---|---|
| 약 이름, 성분명, 약별 3줄 안내, 상호작용 사례 변경 | `src/data.js` |
| 화면 글자, 버튼, 기록 기능 변경 | `src/App.jsx` |
| 색상, 크기, 간격, 모바일 화면 변경 | `src/style.css` |
| 브라우저 탭 제목 변경 | `index.html` |

예를 들어 타이레놀 이름을 바꾸려면 `src/data.js`에서 `id: "tylenol"`을 찾고, 바로 아래의 `name` 값을 수정하세요. **성분이나 주의 문구는 실제 제품 정보와 공식 자료를 확인한 뒤** 수정해야 합니다.

줄 정렬은 VS Code에서 `Shift + Alt + F`를 누르거나, 프로젝트 터미널에서 아래 명령으로 전체 소스를 정리할 수 있습니다.

```bash
npm run format
```

## 4. 수정한 웹을 올리기

수정이 끝나면 터미널에서 다음을 실행합니다.

```bash
npm run build
npm run preview
```

`npm run preview`가 보여주는 로컬 주소에서 최종 화면을 확인하세요. 이후 프로젝트에 새로 만들어진 **`dist` 폴더 안의 `index.html`과 `assets` 폴더**를 웹 호스팅의 공개 폴더에 올립니다. `src`, `node_modules`, `package.json`은 웹 업로드 대상이 아닙니다. 기존 `MediSync_AI_웹업로드용.zip`은 제가 만든 원본 빌드이므로, 코드를 수정했다면 **새로 만든 `dist`**를 올리세요.

## 5. 데모 범위

- 약 검색과 일정 등록, 복용 완료·미복용 기록, 놓쳤을 때 3줄 안내
- 일부 약·영양제·음식 조합의 주의 정보와 공식 자료 링크
- 날짜별 기록, 최근 7일 현황, JSON 백업
- 약 봉투 사진 OCR 및 샘플 인식

복용 기록은 **현재 브라우저에만** 저장됩니다. 사진 OCR은 처음에 한국어 인식 파일을 받기 위해 인터넷이 필요할 수 있습니다. 브라우저 알림은 페이지가 열려 있을 때만 동작합니다.

이 앱은 **교육용 데모**입니다. 실제 복용량·복용 간격·약 변경은 처방 지시와 제품 설명서를 따르고 의료진 또는 약사에게 확인하세요.
