# OCR 전후 비교 도구 (개발용 · 배포에 포함되지 않음)

같은 사진으로 기존 OCR(`baselineOcr.js`, 2026-11-25 개편 전 코드)과 개선 OCR(`src/browserOcr.js`)을 비교한다.

## 시험 사진 (`set/`)
- `real-a.jpg`, `real-b.jpg`: 프로젝트에 있던 실제 약 봉투 사진 (428×276, 480×300). 정답은 확대 사진을 보고 사람이 적은 것이라 틀린 글자가 있을 수 있음
- `s1*`, `s2*`: `make-set.cjs`로 만든 합성 봉투 (정답을 정확히 앎). `c` = 색 있는 표
  - `clean` 1200px · `small` 480px로 축소 · `blur` 800px + 흐림 · `rot4`/`rot8` 4°/8° 기울임
- 정답: `set/gt.json`

## 실행
```
npm run prepare:assets           # OCR 언어 파일 준비 (한 번)
node bench/run-compare.mjs       # 전체 22장, 기존/개선 둘 다 (Playwright 필요: npm i -D playwright)
node bench/run-compare.mjs s1-clean,real-b improved
```

## 지표
- CER/WER: 정답 줄마다 가장 가까운 OCR 줄과의 글자/단어 편집거리 비율 (낮을수록 좋음)
- 이름/지시 필드: 정리된 결과(`src/ocrStructure.js`)의 약 이름이 정답과 똑같은 비율, 복용 지시(한 번에·횟수·기간)가 모두 맞은 비율
- 수정 필요: 약마다 이름·지시 2칸 중 사용자가 고치거나 채워야 하는 칸 수
- 시간: 브라우저(Claude 작업 환경 Chromium)에서 한 장 읽는 데 걸린 시간 중앙값. 폰에서는 다를 수 있음
